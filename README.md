# Ígor Souza — Landing Page Luxury

Landing page responsiva para a consultoria de performance e estética feminina de Ígor Souza. A direção de arte combina uma estrutura brasileira de conversão com linguagem editorial premium: verde-petróleo quase preto, dourado champanhe, serifada de alto contraste, botões claros e fotografia cinematográfica do especialista.

## Rodar o projeto

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Organização

- `src/components/`: hero, navegação e seções da landing page.
- `src/data/content.ts`: links e listas editáveis.
- `src/styles/global.css`: layout, design system, animações e responsividade.
- `public/assets/media/igor-hero-desktop.png`: imagem cinematográfica da hero desktop.
- `public/assets/media/igor-hero-mobile.png`: composição vertical exclusiva da hero mobile.
- `public/assets/media/program-*.png`: fotografias editoriais distintas para hipertrofia, emagrecimento e definição corporal.
- `CONTENT-SOURCES.md`: fatos públicos usados e limites de conteúdo.

## Conteúdo que ainda depende do cliente

- Logo oficial, caso exista uma versão aprovada.
- Fotografias adicionais para variar as imagens das seções internas.
- Resultados e depoimentos reais com autorização de uso.

Nenhum número de resultado, depoimento ou credencial foi inventado. Todos os CTAs apontam para o formulário público de aplicação.
